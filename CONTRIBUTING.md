# contributing

fetchloom contributions keep research inputs reproducible across supported platforms.

start with the [developer guide](docs/dev/README.md) for setup, component ownership and the smallest relevant test. follow the [engineering loop](docs/dev/engineering/README.md) before sending a change, and use [style](docs/dev/style.md) for prose, comments and commits.

update the owning user or developer page when behavior changes. [benchmarking](docs/dev/engineering/benchmarks.md) covers evidence for performance claims; [decisions](docs/dev/decisions.md) explains the boundaries to preserve.
